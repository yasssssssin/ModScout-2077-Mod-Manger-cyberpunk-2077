# Security

## Reporting a vulnerability

Please do not publish API keys, access tokens, personal configuration files, or sensitive logs in public issues.

If you believe you have found a security vulnerability in ModScout 2077, contact the repository owner privately through GitHub rather than posting exploit details publicly.

## Nexus Mods API keys

- Use your own Nexus Mods API key.
- Keep the key in the application's local configuration.
- Never commit the configuration file or include a key in screenshots, logs, bug reports, or support messages.
- If a key is accidentally published, revoke it in your Nexus Mods account and create a replacement.
